# Vietnamese Visual Question Answering Dataset

Vietnamese image/question/answer data maintained by **Ouyangxuelili** for the
Vietnamese VQA Distillation project.

The repository contains the VLSP 2023 train and development annotations plus
their available images. It is intended for Vietnamese visual question
answering research and evaluation.

## Files

- `vlsp2023_train_data.json`: training annotations.
- `vlsp2023_dev_data.json`: development annotations.
- `images/`: image assets referenced by the annotations.

## Provenance

The data originates from the VLSP 2023 Visual Reading Comprehension task. This
Hub repository is the project-maintained distribution. Users are responsible
for following the original VLSP data terms when redistributing or using the
assets.
